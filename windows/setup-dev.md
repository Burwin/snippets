# Setup Windows

This talks about what we want to install and configure to setup a fresh Windows installation as a dev environment. There should be a corresponding script file that actually implements these ideas.

## Install packages

- VS Community / Rider: Choose Rider if you already have a license available.
- WSL
- Docker Desktop
- VSCode
- JetBrains Mono fonts
- Starship prompt for terminal
- .NET SDK
- Chrome
- git
